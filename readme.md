## Description

A  Pomodoro Timer web application designed to improve productivity and time management. It includes customizable work and break sessions, task management, a built-in stopwatch, progress tracking.
## Features

- The application allows users to create tasks.
- track completed work.
- User  able to start stop and resume a pomodoro timer.
- Play a sound when a session ends to notify the user.
- Celebration animation when all tasks are completed.
